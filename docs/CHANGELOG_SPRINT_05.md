# Sprint 5 — Cloud Sync

## Entregas

- Cliente Supabase inicial.
- Tabela `diligencias` no PostgreSQL.
- Persistência em nuvem para cadastro, edição e arquivamento.
- Fallback local quando Supabase não estiver configurado.
- Botão para sincronizar dados locais com a nuvem.

## Decisão técnica

A Sprint utiliza uma política temporária sem login para permitir sincronização imediata entre computador e celular. A autenticação será adicionada posteriormente.
