# LexControl Principles

## Lema

Tecnologia para que o advogado se preocupe apenas em advogar.

## Slogan complementar

Menos burocracia. Mais advocacia.

## Princípios

1. O advogado nunca deverá digitar a mesma informação duas vezes.
2. Nenhuma tarefa repetitiva deverá depender da memória do advogado.
3. O sistema deve antecipar necessidades.
4. A interface deve transmitir tranquilidade, organização e confiança.
5. Toda funcionalidade deve economizar tempo ou reduzir risco.
6. O sistema deve crescer sem perder simplicidade.

## Regra de ouro

Se uma tarefa puder ser automatizada, ela não deverá depender da memória do advogado.
